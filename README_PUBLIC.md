## 1. 这是什么

三个长期课题，加一套从它们提炼的领域无关方法论：

| 资产 | 内容 | 真值层级 |
|---|---|---|
| **EMF** | 认知方法论框架：8 标签真值分层、12 条元规则、11 条机器审计规则、自动化负向测试 | 工具（可复现） |
| **统一定理** | 联合鞍点鬼项相消：`A_n−3B_n ≡ (2n/m)h_n − C_n` 精确恒等式、1/8 不动点残差、共振闭式 `C(m)=√2·e^{−iπm/8}`、共振速率 `√(mπ²/24)` | `THEOREM-COND` + `EMPIRICAL`（强证据 ≤1.05e−4） |
| **π^π 专项** | 归约链走到最远 + 缺口最小化（F-12：方法论一轮内抓住自身无效推论） | `GAP-OPEN` |

**可迁移的方法论成果**（本仓库的核心价值）：

1. **证伪 ≠ 废止**——FALSIFIED 是"暂定拒绝"，保留记录、可条件复活
2. **零违例 ≠ 精确**——数值地板现象不构成精确性证明（F45/F49 教训）
3. **覆盖率表格 ≠ 覆盖率**——审计器演进必须重跑负向测试（GAP-03）
4. **残差在 K→2K 下冻结且非零 = 真实修正项判据**（排除截断尾与舍入）
5. **3×3 最小二乘病态**（共线基函数放大噪声、捏造幻觉系数）→ **Richardson 外推**（无矩阵求逆）
6. **负向测试**：自审查不出"漏检"，只能靠故意植入违规暴露
